# Obolune AI Foundry — Cloud Workspace

Status: DECIDED direction / EXPERIMENTAL implementation.

## Purpose
A small, rebuildable cloud work environment for improving the systems that make later project work cheaper, safer and more autonomous.

## Initial project set
- Botte Secrète — execution/reliability/evidence work in proven scope; experimental capability extensions.
- Parcimonia — EXPERIMENTAL cost/context/compute optimization.
- Bellium-AI — small-model/asset-intelligence experiments.
- Ultimate Odycer Tools Suite — experimental shared contracts only.
- Kanban — cockpit/task projection once the actual Kanban Neo system is identified. Do not guess its repository/API.

Ultimate Odycer, StoryCore, Le Lié and other product projects remain outside the initial core and can later consume Foundry capabilities.

## Cloud Working Knowledge
The cloud wiki is a cache/index, not a second source of truth.

Core:
- START-HERE
- PROJECT-MAP
- CURRENT-STATE
- DECISIONS
- CORRECTIONS
- POLICIES
- CAPABILITIES
- COST-ROUTING
- SOURCES

Project cards are compact and point to canonical GitHub/Kanban/evidence refs.

## Knowledge budget
Tier 0: core orientation.
Tier 1: project card.
Tier 2: relevant canonical docs.
Tier 3: exact code/issues/PR/evidence.
Tier 4: broader investigation.

Deeper tiers are loaded only when justified.

## Learning Inbox
New discoveries/corrections/benchmarks enter as PROPOSED with provenance. Promotion follows epistemic gates; cloud observations do not silently rewrite canonical project truth.

## Security
Least privilege; no secrets in wiki/repos/prompts/manifests/evidence; provider/workspace security is an upper bound; production/release/commerce/high-consequence changes remain approval-gated.

## RSI sandbox
Observe -> propose -> isolated experiment -> benchmark -> compare -> promote/reject.
RSI may improve skills/tools/workflows/pipelines but cannot weaken safety/authority policies or auto-promote itself to production.

## Rebuildability / exit
Essential state must be exportable/reconstructable from canonical repositories, manifests, checkpoints and evidence. No essential project truth may exist only inside the cloud provider.

## Health
Track source staleness, policy/adapter drift, repo refs, orphaned work, pending checkpoints, stale evidence and budget/quota state.

## Bootstrap
A fresh worker loads: environment manifest -> policies/corrections -> relevant project card -> active Work Graph/checkpoint -> deeper sources only as needed.
