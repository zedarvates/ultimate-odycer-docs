# Obolune Multi-Game Creator Platform — Roadmap Addendum

Status: DECIDED direction / EXPERIMENTAL implementation. Cross-game infrastructure; it does not redefine any individual game's identity.

## SYSTAI
DECIDED direction: creator-facing project interface/orchestration for intent, unresolved questions, decisions, state and delegation. Concrete orchestration remains experimental. ChatGPT/Dots/local models are replaceable candidate providers/executors behind SYSTAI.

## Genre neutrality
The creator core MUST NOT assume MMORPG, ARPG, FPS, strategy, planetary simulation or another genre. Genre/game-specific features are composable capabilities selected by each project/Game DNA.

Ultimate Odycer's planetary-life simulation, high customization, MMORPG/VR and optional science-depth concepts are HISTORICAL/product-specific context unless explicitly selected for a current game.

## Reuse before creation
Reuse verified existing tools/contracts. Do not recreate World Compiler or JSON Template Registry. Consume editors according to actually proven status. Locate existing Plant Editor work before proposing a new plant/flora editor.

## Experimental foundations
Game DNA/Design Graph; Universal Entity Contract; Tool Capability Registry; Project Knowledge Graph; Constraint/Budget Engine; Provenance/Rights Ledger; Synthetic Playtest Lab; Build/Release Evidence Graph; Migration Engine; SYSTAI explainability.

## Target loop
Conversation -> SYSTAI -> project/Game DNA -> declared capabilities -> specialized tools/editors -> build/compiler appropriate to that game -> validation -> playtest/evidence -> human approval -> release.

This target is not a claim that every stage is already integrated.
