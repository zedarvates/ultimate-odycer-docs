# Cross-Project Intelligence Platform

Status: EXPERIMENTAL architecture / bounded experiments.

## Goal
Reuse proven capabilities through small contracts without merging projects into a monolith.

## Established vs experimental
ESTABLISHED: Botte Secrète provides execution/reliability/evidence-oriented mechanisms in its proven scope.
EXPERIMENTAL: Capability Graph routing, Parcimonia routing, ShadowGraph and cross-project SYSTAI federation. Do not describe them as production control-plane behavior.

## Target composition
Human -> SYSTAI (staged project interface) -> project-specific state/contracts -> candidate capability selection -> specialized project/tool -> validation/evidence.

Botte Secrète may supply execution/evidence primitives. Parcimonia may supply cost/compute recommendations where proven. Neither role is widened by wording alone.

## ShadowGraph rule
Do not build a universal framework by assumption. Promote shared primitives only after cross-domain evidence.

## Invariants
Domain authority stays in its domain; external models/tools use declared capabilities/policies; high-consequence mutations require approval; provenance/evidence follow outputs; shared contracts use versioned migrations; product-specific history does not define cross-project scope.
