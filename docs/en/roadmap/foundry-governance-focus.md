# AI Foundry — Governance & Focus Layer

Status: DECIDED direction / EXPERIMENTAL implementation.

## Purpose
Help a very small human team govern many projects without losing priorities, endlessly expanding experiments or wasting scarce human attention. These mechanisms govern work; they do not infer or judge personality.

## Goal hierarchy
Goal -> Program -> Milestone -> Outcome -> Workstream -> Job.
Active work should trace to an active outcome or be explicitly marked exploratory/maintenance. Orphaned work is surfaced, never silently deleted.

## Experiment discipline
Every experiment declares hypothesis, max time/cost, metrics, stop/success/failure criteria and promotion path. Lifecycle: ACTIVE / PAUSED / WATCH / ARCHIVED / SUPERSEDED. History/evidence is preserved.

## Learning from failure and assumptions
Failure Memory stores bounded failed approaches and conditions.
Assumption Ledger keeps assumptions distinct from facts/decisions and tracks unknown/supported/falsified.
Uncertainty Budget highlights material unknowns before expensive dependent work.

## Capability governance
Capability Gap Detector reports missing proven capabilities.
Build/Buy/Integrate Decision Brief compares alternatives.
Tool Retirement review proposes deprecation only from measured evidence and maintenance value.

## Resource governance
Opportunity Cost complements direct cost.
Idle-Time Planner finds useful low-consequence work while critical paths are blocked.
Human Attention Budget batches related decisions without hiding them.
Daily/Weekly Command Brief provides evidence-linked operational summary.

## Autonomy
Per-job levels:
- L0 Observe
- L1 Investigate
- L2 Prepare isolated/reversible artifacts
- L3 Bounded reversible execution
- L4 Explicitly authorized operations
Human-only categories remain non-delegable by policy.

Effective autonomy can only be narrowed by provider/workspace/machine/SYSTAI/job/human policy intersections.

## Reproducibility
Important experiments use reproducibility capsules. Manual/stochastic/non-deterministic work is labelled honestly.
