# Obolune Creator — Experience & Service Expansion

Status: mixed. See per-section epistemic status.

## Immediate bounded experiments

### EXPERIMENTAL — Playable Slice Builder
Goal: turn a game idea/project into the smallest playable slice that demonstrates its declared player fantasy.

Planning output:
- fantasy/experience to demonstrate;
- mechanics required;
- minimum narrative/content context;
- minimum assets/UI/audio;
- technical/runtime dependencies;
- validation/playtest evidence;
- budget/time range;
- explicit exclusions.

A playable slice is not automatically a vertical slice, demo or production promise.

### EXPERIMENTAL — Mechanic Lab / Mechanic DNA
Genre-neutral representation and prototyping of mechanics: intent, inputs, states/transitions, feedback, tuning, dependencies, failure modes, accessibility, authority/network constraints where applicable, prototype target and measurable tests.

Do not claim subjective “fun” from automated metrics alone.

### EXPERIMENTAL — Player Experience Graph
Represent intended player progression through knowledge, capability/mastery, challenge, feedback/reward and narrative context. Link to mechanics/story/tutorial/progression without merging their schemas prematurely.

Initial use: detect declared sequencing/coverage gaps. It does not numerically prove player enjoyment.

## PROPOSED service directions
- Natural-goal intake: user describes the problem instead of choosing a service.
- Game Doctor: evidence-backed findings and options.
- Idea -> Feasibility: risks/resources/minimum uncertainty-reducing prototype.
- Game Feel Lab: camera/input/timing/feedback/haptics experimentation.
- Balance Lab: simulation with assumptions/limits exposed.
- Accessibility Builder/Checker.
- Localization & Culturalization.
- Mod / UGC Builder.
- Game Preservation / Migration.
- Post-launch / Live Game Assistant.
- Capability Marketplace/library: versioned capabilities, not an unrestricted agent marketplace.

## Promotion rule
Each PROPOSED direction must pass PROPOSED -> EXPERIMENTAL -> evidence -> explicit decision before being described as an adopted service/capability.
