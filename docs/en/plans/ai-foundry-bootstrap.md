# AI Foundry Bootstrap Plan

Status: EXPERIMENTAL planning.

## Phase 0 — identify
1. Locate/confirm actual Kanban Neo implementation and access surface.
2. Confirm selected repository refs and minimum required permissions.
3. Define canonical-source map and cloud provider constraints.

## Phase 1 — read-only Foundry
1. Environment Manifest v0.
2. START-HERE + Knowledge Manifest.
3. Project cards for Botte Secrète, Parcimonia, Bellium-AI and Tools Suite.
4. Knowledge staleness detector.
5. Read-only Kanban projection.
6. Cost/quota dashboard.
7. Backup/export test.

Exit: fresh worker can orient, inspect tasks and produce a plan without writing project code.

## Phase 2 — isolated work
Allow branch-only experimental work for explicitly permitted repos. Require Work Handoff, permission intersection, Return Receipt, Evidence Index and checkpoints.

Exit: one bounded experiment can be interrupted/rebuilt/reviewed with no production mutation.

## Phase 3 — RSI sandbox
Run one skill/workflow/pipeline improvement through baseline -> experiment -> benchmark -> Decision Brief -> human/policy promotion/rejection.

## Non-goals
No merge/release/publish autonomy; no production secrets; no automatic credit purchase; no guessed Kanban integration; no migration of all projects into cloud; no provider lock-in.
