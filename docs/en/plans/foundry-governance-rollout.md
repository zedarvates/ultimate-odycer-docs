# Foundry Governance Rollout

Status: EXPERIMENTAL planning.

## First tranche
1. Goal Hierarchy schema and orphan-work projection.
2. Experiment Portfolio schema with stop criteria.
3. Failure Memory + Assumption Ledger.
4. Human Attention projection.
5. Per-job Autonomy Level metadata.

Exit: read-only dashboard can explain why active work exists, what experiments should be reviewed, what assumptions/failures matter, and which human decisions are blocking.

## Second tranche
Opportunity cost; idle-time planner; uncertainty budget; capability gaps; dependency radar; reproducibility capsules.

## Third tranche
Build/Buy/Integrate briefs; measured tool redundancy review; daily/weekly command briefs integrated with Kanban once actual Kanban Neo is identified.

## Guardrail
No opaque global priority score. Strategic priorities remain human-declared. Planners explain trade-offs and may propose, not silently rewrite goals.
