# Experience-Creation Experiment Plan

Status: EXPERIMENTAL planning.

## Phase A — contracts only
1. Mechanic DNA v0 with one genre-neutral fixture.
2. Player Experience Graph v0 with explicit subjective/observable boundary.
3. Playable Slice Plan v0 referencing existing Game/Story/Art/project contracts instead of copying them.

Exit: schemas/fixtures validate; no runtime integration claim.

## Phase B — one bounded synthetic project
Use one small synthetic game concept, not Ultimate Odycer or Le Lié by default, to avoid genre leakage.
- declare one player fantasy;
- model 1–2 mechanics;
- attach minimal narrative context if needed;
- produce a slice plan;
- identify sequence gaps and evidence requirements.

Exit: reproducible planning artifact and documented limitations.

## Phase C — real-project comparison
Only after Phase B, apply to two deliberately different projects/genres and compare what fields survive without distortion.

## Deferred PROPOSED backlog
Game Doctor; feasibility; Game Feel; Balance; Accessibility; Localization; UGC; preservation/migration; post-launch assistance; capability marketplace.

No deferred item becomes active merely because it appears in this plan.
