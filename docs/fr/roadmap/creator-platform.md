# Plateforme de création multi-jeux Obolune — Complément de feuille de route

Statut : direction DÉCIDÉE / implémentation EXPÉRIMENTALE. Infrastructure inter-jeux ; elle ne redéfinit l’identité d’aucun jeu.

## SYSTAI
Direction DÉCIDÉE : interface et orchestration de projet tournée vers les créateurs pour l’intention, les questions non résolues, les décisions, l’état et la délégation. L’orchestration concrète reste expérimentale. ChatGPT/Dots/les modèles locaux sont des fournisseurs ou exécuteurs candidats remplaçables derrière SYSTAI.

## Neutralité de genre
Le cœur créateur NE DOIT PAS supposer un MMORPG, ARPG, FPS, jeu de stratégie, simulation planétaire ou autre genre. Les fonctions propres à un genre ou jeu sont des capacités composables choisies par chaque projet/Game DNA.

La simulation de vie planétaire, la personnalisation poussée, le MMORPG/VR et les concepts scientifiques optionnels d’Ultimate Odycer constituent un contexte HISTORIQUE ou propre au produit, sauf sélection explicite pour un jeu actuel.

## Réutiliser avant de créer
Réutiliser les outils et contrats existants vérifiés. Ne pas recréer World Compiler ni JSON Template Registry. Consommer les éditeurs selon leur statut réellement prouvé. Localiser le travail Plant Editor existant avant de proposer un nouvel éditeur de plantes/flore.

## Fondations expérimentales
Game DNA/Design Graph ; Universal Entity Contract ; Tool Capability Registry ; Project Knowledge Graph ; Constraint/Budget Engine ; Provenance/Rights Ledger ; Synthetic Playtest Lab ; Build/Release Evidence Graph ; Migration Engine ; explicabilité SYSTAI.

## Boucle cible
Conversation -> SYSTAI -> projet/Game DNA -> capacités déclarées -> outils/éditeurs spécialisés -> build/compilateur adapté au jeu -> validation -> playtest/preuves -> approbation humaine -> publication.

Cette cible n’affirme pas que chaque étape est déjà intégrée.
