# Plan d’expériences de création d’expérience

Statut : planification EXPÉRIMENTALE.

## Phase A — contrats uniquement
1. Mechanic DNA v0 avec une fixture neutre en matière de genre.
2. Player Experience Graph v0 avec une frontière explicite entre subjectif et observable.
3. Playable Slice Plan v0 référençant les contrats existants de jeu, récit, art et projet au lieu de les copier.

Sortie : les schémas et fixtures se valident ; aucune affirmation d’intégration à l’exécution.

## Phase B — un projet synthétique borné
Utiliser un petit concept de jeu synthétique, et non Ultimate Odycer ou Le Lié par défaut, afin d’éviter les fuites de genre.
- déclarer une seule fantaisie de joueur ;
- modéliser une ou deux mécaniques ;
- joindre un contexte narratif minimal si nécessaire ;
- produire un plan de tranche jouable ;
- identifier les lacunes d’enchaînement et les besoins de preuve.

Sortie : artefact de planification reproductible et limites documentées.

## Phase C — comparaison sur des projets réels
Uniquement après la phase B, appliquer à deux projets ou genres volontairement différents et comparer les champs qui subsistent sans distorsion.

## Backlog PROPOSÉ différé
Game Doctor ; faisabilité ; Game Feel ; équilibrage ; accessibilité ; localisation ; UGC ; conservation/migration ; assistance après lancement ; place de marché de capacités.

Aucun élément différé ne devient actif du seul fait de figurer dans ce plan.
