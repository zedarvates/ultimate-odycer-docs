# Déploiement de la gouvernance Foundry

Statut : planification EXPERIMENTAL.

## Première tranche
1. Schéma Goal Hierarchy et projection du travail orphelin.
2. Schéma Experiment Portfolio avec critères d'arrêt.
3. Failure Memory + Assumption Ledger.
4. Projection Human Attention.
5. Métadonnées de niveau d'autonomie par job.

Critère de sortie : le tableau de bord en lecture seule peut expliquer pourquoi le travail actif existe, quelles expériences doivent être revues, quelles hypothèses et quels échecs comptent, et quelles décisions humaines bloquent.

## Deuxième tranche
Coût d'opportunité ; planificateur des périodes d'attente ; budget d'incertitude ; lacunes de capacités ; radar des dépendances ; capsules de reproductibilité.

## Troisième tranche
Decision Briefs de construction, achat ou intégration ; revue mesurée de la redondance des outils ; synthèses opérationnelles quotidiennes et hebdomadaires intégrées à Kanban une fois le véritable Kanban Neo identifié.

## Garde-fou
Aucun score global opaque de priorité. Les priorités stratégiques restent déclarées par l'humain. Les planificateurs expliquent les compromis et peuvent proposer ; ils ne réécrivent pas silencieusement les objectifs.
