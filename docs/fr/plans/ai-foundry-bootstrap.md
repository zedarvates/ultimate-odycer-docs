# Plan d'amorçage AI Foundry

Statut : planification EXPERIMENTAL.

## Phase 0 — identifier
1. Localiser et confirmer l'implémentation réelle de Kanban Neo et sa surface d'accès.
2. Confirmer les références des dépôts sélectionnés et les permissions minimales nécessaires.
3. Définir la carte des sources canoniques et les contraintes du fournisseur cloud.

## Phase 1 — Foundry en lecture seule
1. Environment Manifest v0.
2. START-HERE + Knowledge Manifest.
3. Fiches projet pour Botte Secrète, Parcimonia, Bellium-AI et Tools Suite.
4. Détecteur de connaissances périmées.
5. Projection Kanban en lecture seule.
6. Tableau de bord des coûts et quotas.
7. Test de sauvegarde et d'export.

Critère de sortie : un nouvel intervenant peut s'orienter, inspecter les tâches et produire un plan sans écrire dans le code des projets.

## Phase 2 — travail isolé
Autoriser le travail expérimental sur branche uniquement pour les dépôts explicitement permis. Exiger Work Handoff, intersection des permissions, Return Receipt, Evidence Index et points de reprise.

Critère de sortie : une expérience bornée peut être interrompue, reconstruite et revue sans mutation de la production.

## Phase 3 — bac à sable RSI
Faire passer une amélioration de skill, workflow ou pipeline par référence initiale -> expérience -> benchmark -> Decision Brief -> promotion ou rejet par décision humaine ou politique.

## Hors objectifs
Aucune autonomie de fusion, release ou publication ; aucun secret de production ; aucun achat automatique de crédits ; aucune intégration Kanban devinée ; aucune migration de tous les projets dans le cloud ; aucune dépendance exclusive à un fournisseur.
